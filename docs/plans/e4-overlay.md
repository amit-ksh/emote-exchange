# E4 overlay plan

October 28, 2026. Build a transparent 1920 x 1080 broadcast composition in the existing React/plain-CSS client. The ignored reference images guide soft panel edges, numerical hierarchy and restrained accents. Keep the spec's near-black glass, green/red direction, Twitch purple accent and local JetBrains Mono/Space Grotesk. No package dependency is planned.

1. Add a genuine session-opening Net Worth baseline for each Trader, persisted with a small migration. Opening Bell snapshots current worth; new Traders start against Starting Coins. Existing migrated Traders show unavailable change until the next Bell rather than inventing a baseline. Test engine and persistence behavior first.
2. Build a strict, explicit client reader and pure presentation rules for URL widget selection, safe colors/images, hottest-Listing selection (20-second minimum), five eight-second Feed toasts, and one four-second Banner with at most 32 pending. Coalesce kind/Ticker, prioritize RAID > HALT > MOON/CRASH > IPO > rest, then drop the oldest lowest-priority item on overflow. Stable IDs prevent replay on SSE coalescing/reconnect.
3. Replace the placeholder overlay with Tape, canvas Chart, top-five Board, Feed, Banners and SIM. Preserve the spec's widget sizes and reserve the central gameplay area. Position the 900-pixel Banner clear of the right Chart. Batch numeric updates to once per second; CSS handles the 60 px/s Tape, price flashes, rank transitions and restrained Banner motion. Reduced motion uses fades and a static paged Tape. Pause animations/drawing while hidden. Cards/sound stay P1; `sound=off` remains accepted.
4. Bundle fonts and licenses locally. Check contrast over worst-case bright footage, arrows plus color, fixed minimum type sizes, long names/large numbers, disconnected/empty/paused/Halted states and selective widget URLs. Keep browser data display-only.
5. Run Opening day and Pump and dump in a separate keyless demo data directory, so visual QA cannot alter the streamer's saved live Portfolio. Inspect the actual `/overlay` at 1920 x 1080 and 960 x 540, including reduced motion. Measure Chrome performance during Pump and dump and record observed evidence; actual OBS is a separate manual gate. Run repository checks, fix review findings, update verification/status and commit E4.

This written plan precedes implementation. It does not claim a filmed planning session or any OBS/performance result before it is observed.
