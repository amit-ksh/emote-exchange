# Original demo emotes

These 24 SVG drawings were authored for Emote Exchange. They use geometric shapes and original expressions, with no third-party image, font or character assets. Names are the filename without `.svg`; spelling and case are significant. The set stays available without network access.

Third-party provider artwork is fetched at runtime from its CDN and is not bundled here. The provider fixtures in Twitch Kit contain metadata excerpts only.
